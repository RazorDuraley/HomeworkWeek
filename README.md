# 📚 Homework Tracker

**Веб-приложение для управления домашними заданиями студентов.**

Расписание пар, дедлайны, общие и личные задачи — всё в одном месте, работает на телефоне.

🔗 **[Открыть приложение](https://iv-623top.duckdns.org)**

---

## 🎯 Зачем это нужно

Студенты сталкиваются с одной и той же проблемой: домашки разбросаны по чатам, блокнотам и голове. Кто-то записал, кто-то забыл, кто-то переспрашивает у группы по десять раз.

**Homework Tracker** решает это:

- 📅 **Расписание пар** подтягивается автоматически — не нужно вбивать вручную
- 📝 **Общие домашки** видят все — не нужно переспрашивать «что задали?»
- 🔒 **Личные домашки** — для своих заметок, видны только вам
- ✅ **Отметки о выполнении** — видно, кто уже сдал
- 📱 **Работает на телефоне** — добавляется на главный экран как приложение
- 🎨 **Цветовая индикация** — свои задачи синие, общие оранжевые, выполненные зелёные

---

## 🚀 Как начать пользоваться

1. Открой [https://iv-623top.duckdns.org](https://iv-623top.duckdns.org) на телефоне или компьютере
2. Нажми **«Зарегистрироваться»** — введи email и пароль
3. Выбери свой предмет из списка — расписание уже загружено
4. Добавляй домашки: **общие** (видят все) или **личные** (только ты)
5. Отмечай выполненные — они станут зелёными

## 🛠️ Технологии

### Frontend
- React 19 + Vite
- React Context для авторизации
- Axios с interceptors для JWT
- CSS3 (адаптивная вёрстка, тёмная тема)

### Backend
- ASP.NET Core 8 Web API
- Entity Framework Core 8 (Code First, миграции)
- PostgreSQL 16
- JWT-аутентификация с ролевой моделью (Admin / Moderator / User)
- ASP.NET Core Identity для управления пользователями

### Инфраструктура
- Docker + Docker Compose
- Nginx как реверс-прокси
- Ubuntu 22.04 VPS
- HTTPS через Let's Encrypt (автопродление)
- systemd для управления сервисами
- UFW + Fail2ban для безопасности
- GitHub Actions для CI/CD (автодеплой при пуше в `main`)

---

## 🏗️ Архитектура

```
Клиент (React SPA)
        ↓
Nginx (реверс-прокси, SSL)
        ↓
ASP.NET Core API (порт 8080)
        ↓
PostgreSQL
```

React-статика раздаётся тем же Nginx.

## 🚀 Локальный запуск

### Требования
- .NET 8 SDK
- Node.js 20+
- PostgreSQL 16 (или Docker)
- Docker (опционально)

### Backend

```bash
cd HomeworkApi
export DATABASE_URL="postgresql://postgres:password@localhost:5432/homework"
export JWT_KEY="your-secret-key-at-least-32-chars"
dotnet restore
dotnet ef database update
dotnet run
```

API будет доступен на `http://localhost:8080`, Swagger — на `/swagger`.

### Frontend

```bash
cd homework-frontend
# Укажи URL бэкенда в src/api.js
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`.

### Docker

```bash
docker compose up -d
```

## 🔄 CI/CD

Каждый пуш в `main` автоматически:

1. Собирает .NET-бэкенд и React-фронтенд
2. Загружает артефакты на VPS через rsync
3. Перезапускает сервисы через systemd
4. Применяет миграции EF Core при старте приложения

Настроено через GitHub Actions (`.github/workflows/deploy.yml`).

## 🔐 Безопасность

- **Пароли** — хешируются через ASP.NET Core Identity (PBKDF2)
- **JWT-токены** — подпись HMAC-SHA256, срок жизни 7 дней
- **Роли** — Admin / Moderator / User, проверка через `[Authorize(Roles = "...")]`
- **HTTPS** — обязателен, сертификат Let's Encrypt с автопродлением
- **UFW** — открыты только порты 22, 80, 443
- **Fail2ban** — блокировка SSH-ботов после 3 неудачных попыток
- **CORS** — настроен на разрешённые источники
